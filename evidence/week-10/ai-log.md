# AI LOG - WEEK 10
## Project KursusKu

### 1. Tujuan Penggunaan AI

AI digunakan sebagai alat bantu dalam proses
pengembangan dan perbaikan aplikasi KursusKu
menggunakan framework Laravel.

### 2. Riwayat Penggunaan AI

| No | Aktivitas | Bantuan AI |
|---|---|---|
| 1 | Database | Membantu memeriksa struktur database |
| 2 | Course Seeder | Membantu membuat 8 data kursus |
| 3 | CourseController | Membantu menyusun fungsi CRUD |
| 4 | Routing | Membantu mengatur route kursus |
| 5 | Form Kursus | Membantu membuat form tambah dan edit |
| 6 | Validasi | Membantu memperbaiki validasi input |
| 7 | Tampilan | Membantu memperbaiki CSS dan tabel kursus |
| 8 | Testing | Membantu menyusun test cases |
| 9 | Dokumentasi | Membantu menyusun evidence Week 10 |

### 3. Tools yang Digunakan

- ChatGPT
- Visual Studio Code
- Laravel
- PHP
- MySQL
- Laragon
- Git dan GitHub

### 4. Verifikasi Hasil

Setiap kode yang dihasilkan AI diperiksa dan
disesuaikan kembali dengan kebutuhan aplikasi.

Pengujian dilakukan melalui browser, database,
dan fitur yang tersedia pada aplikasi KursusKu.

### 5. Kesimpulan

AI digunakan sebagai pendukung dalam proses
pengembangan aplikasi. Keputusan akhir,
pemeriksaan kode, dan pengujian dilakukan
oleh pengembang.
