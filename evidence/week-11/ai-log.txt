2. TUJUAN PENGGUNAAN AI

AI digunakan sebagai alat bantu dalam proses pengembangan
aplikasi KursusKu.

Tujuan penggunaan AI meliputi:
- Memahami konsep dan struktur Laravel.
- Memeriksa kode program.
- Membantu memperbaiki kesalahan kode.
- Menyusun aturan validasi form.
- Membantu membuat skenario pengujian.
- Menyusun dokumentasi pengujian aplikasi.


3. RIWAYAT PENGGUNAAN AI

1. Pemeriksaan Kode
   Bantuan  : Memeriksa struktur dan sintaks kode Laravel.
   Hasil    : Kode lebih terarah dan mudah dipahami.

2. Controller
   Bantuan  : Meninjau kode CourseController.
   Hasil    : Proses CRUD diperiksa.

3. Form Request
   Bantuan  : Memeriksa StoreCourseRequest dan
              UpdateCourseRequest.
   Hasil    : Aturan validasi disesuaikan.

4. Routing
   Bantuan  : Memeriksa route resource courses.
   Hasil    : Route CRUD diperiksa melalui route:list.

5. Validasi Form
   Bantuan  : Menjelaskan aturan validasi setiap kolom.
   Hasil    : Validasi data disesuaikan dengan kebutuhan.

6. Pengujian
   Bantuan  : Membantu menyusun skenario pengujian CRUD
              dan validasi.
   Hasil    : Tersusun 15 skenario pengujian.

7. Dokumentasi
   Bantuan  : Membantu menyusun test matrix dan evidence.
   Hasil    : Dokumentasi pengujian lebih terstruktur.


4. ATURAN VALIDASI

1. Code
   Required, string, max:20, unique.

2. Name
   Required, string, min:3, max:120.

3. Description
   Nullable, string, max:2000.

4. Fee
   Required, integer, min:0.

5. Quota
   Required, integer, min:1, max:500.

6. Start Date
   Required, date.

7. Status
   Required, in:draft,open,closed.

Catatan:
Pada proses update, kode kursus yang sedang digunakan oleh
data itu sendiri tetap diperbolehkan karena validasi unique
mengabaikan ID kursus tersebut.


5. PENGUJIAN APLIKASI

Berikut skenario pengujian yang disusun:

1. Kode kursus duplikat
   Tujuan: Memastikan kode kursus tidak boleh sama.

2. Nama kursus kosong
   Tujuan: Memastikan nama wajib diisi.

3. Nama kurang dari 3 karakter
   Tujuan: Memastikan batas minimal nama.

4. Deskripsi kosong
   Tujuan: Memastikan deskripsi boleh kosong.

5. Biaya negatif
   Tujuan: Memastikan biaya minimal 0.

6. Biaya bukan angka
   Tujuan: Memastikan biaya harus berupa integer.

7. Kuota 0
   Tujuan: Memastikan kuota minimal 1.

8. Kuota 501
   Tujuan: Memastikan kuota maksimal 500.

9. Kuota 1
   Tujuan: Memastikan batas minimal diterima.

10. Kuota 500
    Tujuan: Memastikan batas maksimal diterima.

11. Tanggal mulai kosong
    Tujuan: Memastikan tanggal wajib diisi.

12. Status tidak valid
    Tujuan: Memastikan status sesuai pilihan.

13. Update kode duplikat
    Tujuan: Memastikan kode tidak menggunakan kode
            milik kursus lain.

14. Update normal
    Tujuan: Memastikan data kursus dapat diperbarui.

15. Delete kursus
    Tujuan: Memastikan data kursus dapat dihapus.
