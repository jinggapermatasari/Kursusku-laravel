# AI Usage Log – Milestone Week-07

Dokumentasi penggunaan ChatGPT sebagai pendukung pembelajaran dan pengerjaan praktikum Pemrograman Web III pada proyek Laravel KursusKu.

| No. | Aktivitas | Prompt atau Pertanyaan | Hasil Bantuan dan Evaluasi |
|---|---|---|---|
| 1 | Memahami struktur Laravel | "Jelaskan bagian-bagian penting dalam struktur proyek Laravel KursusKu." | **Diterima:** Penjelasan mengenai fungsi folder dan file utama Laravel. **Evaluasi:** Struktur dijadikan acuan untuk mengenali lokasi kode program yang digunakan. |
| 2 | Memeriksa konfigurasi route | "Bagaimana cara memeriksa route yang digunakan untuk membuka halaman utama aplikasi Laravel?" | **Diterima:** Panduan menggunakan perintah `php artisan route:list`. **Evaluasi:** Hasil perintah perlu dicocokkan dengan route yang tersedia dalam proyek. |
| 3 | Mengembangkan tampilan halaman | "Berikan panduan menyusun halaman utama menggunakan Blade dan CSS yang mudah dikelola." | **Diterima:** Saran penggunaan template Blade dan pemisahan kode tampilan ke dalam CSS. **Evaluasi:** Penerapan disesuaikan dengan kebutuhan halaman KursusKu. |
| 4 | Mempelajari alur request lifecycle | "Jelaskan proses ketika pengguna membuka halaman Laravel sampai halaman ditampilkan di browser." | **Diterima:** Penjelasan hubungan browser, route, controller, dan Blade View. **Evaluasi:** Penjelasan digunakan untuk menyusun diagram alur aplikasi. |
| 5 | Menyusun dokumentasi proyek | "Bantu tentukan dokumen dan bukti yang perlu disiapkan untuk pengumpulan praktikum Week 07." | **Diterima:** Arahan untuk menyiapkan dokumentasi proyek dan mengelompokkan bukti pengerjaan. **Evaluasi:** Berkas disusun sesuai kebutuhan tugas. |
| 6 | Menyiapkan proyek untuk GitHub | "Jelaskan langkah memeriksa perubahan file dan mengunggah proyek Laravel ke GitHub." | **Diterima:** Panduan pemeriksaan status Git, pembuatan commit, dan pengiriman perubahan ke repositori. **Evaluasi:** Tujuan repositori dan keamanan file konfigurasi diperiksa sebelum upload. |

## Refleksi Penggunaan AI

ChatGPT dimanfaatkan sebagai alat bantu untuk memperdalam pemahaman mengenai Laravel dan mendukung penyelesaian tugas praktikum. Bantuan AI digunakan sebagai referensi dalam mempelajari kode, memahami alur aplikasi, serta menyiapkan dokumentasi. Setiap saran perlu diperiksa dan disesuaikan dengan kondisi proyek agar hasil akhirnya sesuai dengan kebutuhan praktikum.
